## 4. 启动方式

```powershell
npm install
npm run tauri:dev
```

打开后可在“主机”页面填写地址、端口、用户名并点击“验证 TCP 端口”；其他页面显示 P0 骨架空状态。

命令行结构化验证：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/ssh-poc.ps1 `
  -HostName jtdcblj2.zhenergy.com.cn -Port 8022 -UserName u890374m2
```

获得授权测试账号后，追加 `-RunSsh` 或 `-RunSftp`；不要在命令行参数中写密码。
