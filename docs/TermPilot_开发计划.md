# TermPilot 个人版开发计划

版本：2.0  
日期：2026-09-04  
状态：个人实现基线

## 1. 目标和明确边界

TermPilot 仅供本人在当前 Windows x64 电脑上使用，用于本人已获授权的生产和测试 SSH 服务器。不对外发布，不制作安装包，不提供企业部署。

### 必须实现

- 主机新增、编辑、分组、软删除。
- 直连 SSH 和单级 SSH 堡垒机。
- 密码、私钥文件引用、SSH Agent。
- xterm.js 远程 SSH PTY、输入、输出、resize、断线提示。
- SFTP 列表、上传、下载、删除、重命名、新目录、暂停、取消、重试和下载续传；连接后默认访问远端 `~`。
- 本地路径按次选择并校验，远端执行 realpath、符号链接复核和覆盖确认。
- SQLite 本地审计和 JSONL 导出；SHA-256 哈希链校验。
- 默认人工审批、固定只读命令白名单、高危命令阻断。
- 超时、取消和全局急停。
- 一个实际使用的模型 Provider：Ollama 或 OpenAI-compatible 二选一。
- 本地配置、数据库备份和 localhost/隔离环境测试。

### 明确删除

- NSIS/MSI 安装包、自动更新、升级回滚、代码签名和发布流程。
- Windows 10/11 多版本兼容承诺、ARM64 兼容和跨设备迁移。
- 多用户共享、团队协作、云同步、企业 SSO、SIEM、集中审计、企业 CA/mTLS。
- 多级跳板、Telnet、串口和公网 HTTP API。
- OpenAI-compatible 与 Ollama 的同时适配；只实现选定的一个 Provider。
- 项目级 `.termpilot`、Profile 切换和 `.codex` 兼容层。
- Windows Hello/PIN 解锁、复杂凭据包导入和多种密码保存期限。
- CSV 导出、复杂事件重放、后台任务自动恢复。
- 通用 Shell AST 等价分析；不支持任意 Shell 字符串。

## 2. 开发顺序

### P0：本地骨架和数据库（第 1 周）

Tauri/React/Rust 工程、SQLite 迁移、主机 CRUD、统一错误封装、本地配置和日志脱敏。

退出条件：应用可启动，主机可保存/读取，数据库可迁移和备份。

### P1：凭据和 SSH（第 2–3 周）

Credential Manager 引用、密码会话缓存、私钥路径、SSH Agent、主机指纹、localhost SSH 和单级堡垒机连接。

退出条件：密码不落盘；错误密码、指纹变化和连接超时安全失败。

### P2：终端和 SFTP（第 3–5 周）

远程 PTY、resize、输出限流、SFTP 基础操作、远端 `~`/realpath 校验、下载续传和原子替换。

退出条件：localhost/隔离服务器完成终端和文件操作；强制断开后资源释放。

### P3：审计和安全策略（第 5–6 周）

SQLite SHA-256 审计链、JSONL 导出、固定只读白名单、默认拒绝、人工审批、生产主机标记、急停。

退出条件：审计失败时自动执行被阻断；高危命令和白名单参数越界不会执行。

### P4：单一模型和 Agent（第 6–7 周）

接入选定 Provider、上下文脱敏、只读诊断、结构化工具调用、任务取消和限额。

退出条件：模型只能调用白名单工具；模型不可用不影响 SSH/SFTP。

### P5：个人验收（第 8 周）

完成关键 UI、备份恢复、断网/认证失败/磁盘满测试、8 会话基础压力测试和安全回归。

退出条件：个人使用旅程可重复完成，所有 P0 安全缺陷为 0。

## 3. 个人版安全底线

- 默认 `ask_before_execute`。
- 自动执行只允许内置固定只读命令，例如精确的 `df -h`、`pwd`、`whoami`。
- 不接受模型传入 Shell 命令字符串，不执行 `sh -c`、管道、重定向、解释器和动态脚本。
- 生产主机的修改、删除、覆盖、权限和服务操作必须人工确认。
- 密码、私钥、Token、完整终端输出和完整文件内容不得进入 SQLite、日志或模型请求。
- 审计、策略或急停状态异常时安全失败。

## 4. 开始编码前唯一外部阻塞项

1. 堡垒机登录后是否直接进入目标，还是需要菜单/二次跳转。
2. 堡垒机是否支持 PTY、resize、SFTP 和断线重连。
3. 测试账号、主机指纹、隔离 SFTP 目录和凭据有效期。
4. 选择唯一模型 Provider：Ollama 或 OpenAI-compatible。

除以上项目外，不再等待企业资料、发布证书或多用户需求。
