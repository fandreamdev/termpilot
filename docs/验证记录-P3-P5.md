# P3–P5 验证记录

日期：2026-09-03  
范围：凭据、会话/PTY、SFTP 与本地审计

## 模块交付

- `credentials.rs`：Windows Credential Manager 通过 `keyring`、仅本次运行内存保管、密码/私钥/SSH Agent 三种适配、四字段 bundle 严格解析、请求后清零原文、撤销与过期字段；过期时间按 RFC3339 校验，私钥路径必须为现有绝对文件。
- 凭据包句柄仅在当前进程注册并绑定凭据引用，撤销凭据会同步清理句柄，伪造句柄会被拒绝。
- `sessions.rs`：结构化 `session_connect/session_cancel/session_send_input/session_resize/session_disconnect`，request 幂等复用、PTY 1–1000 边界、base64 bytes ≤64 KiB、状态事件；`ssh2` 执行真实 SSH 握手、主机公钥指纹读取、密码/私钥/SSH Agent 认证，并由专用 worker 持有 PTY channel 处理输入、输出、resize 与关闭。
- 首次连接若无已保存指纹会返回待确认指纹，前端确认后重试并绑定 HostKey；指纹变化返回专用阻断错误。
- `transport.rs`：独立 SSH/SFTP 适配层，封装认证、realpath、目录列表、流式上传/下载及远端 CRUD，避免业务 command 文件承载协议细节。
- `sftp.rs`：Workspace 限制、远端路径规范化、防 `..`/UNC/NUL 逃逸、流式 64 KiB 文件复制、20 GiB 上限、覆盖/续传、列表、暂停/恢复/取消和进度事件；本地大文件复制支持并发暂停/恢复/取消控制；无 Workspace 会话通过独立 `transport.rs` 使用真实 SSH SFTP channel 完成列表、上传、下载、删除、重命名和建目录。
- `audit.rs`：脱敏审计 payload、SQLite 追加 SHA-256 哈希链、JSONL/CSV 导出、manifest 文件哈希和离线校验。
- 前端 `TerminalPanel` 使用最新 `@xterm/xterm` 与 `@xterm/addon-fit`，支持有限滚动缓冲、resize 自适应和 base64 输入。
- 前端 `SftpPanel`、`AuditPanel` 和主机 SSH Agent 连接入口。

## 安全边界与已知限制

- 密码/私钥正文不进入 SQLite、审计、事件或 React 持久化状态；持久化凭据通过 Windows Credential Manager `keyring`。
- 连续认证失败达到 3 次后进入 30 秒内存冷却，成功认证会清除失败计数。
- 当前 `ssh2` 传输已完成结构化 DNS/TCP 建链、SSH 握手、首次 HostKey 确认/变化阻断、认证和 PTY worker；由于尚未提供授权 OpenSSH 测试端点，尚未完成真实交互式读写、resize、断线重连的实机证据。
- 有 Workspace 的离线 Mock 会话使用安全本地映射；真实会话使用 SSH SFTP channel。两条路径均执行远端路径约束和本地路径校验；真实端点上的续传/中断恢复仍需授权实机证据。
- 审计导出校验已验证文件篡改检测；跨用户 ACL、强杀恢复和 100 MB 实机续传留待 P9 环境测试。
