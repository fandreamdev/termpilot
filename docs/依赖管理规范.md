# TermPilot 依赖管理规范

## 原则

项目直接依赖采用当前可用的最新稳定版本，并以精确版本写入 `package.json`、`Cargo.toml`；`package-lock.json`、`Cargo.lock` 必须提交，保证本机、CI 和发布构建使用同一组已验证依赖。

不使用 `latest` 标签或无上限的版本范围作为生产依赖声明：它们会让同一提交在不同日期解析出不同代码，无法可靠回滚或复现实机验证。更新依赖时应先查询发布源，再更新锁文件、构建和测试。

## 更新步骤

```powershell
npm outdated --long
npm install
cargo update --manifest-path src-tauri/Cargo.toml
npm test
npm run build
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings
```

任何主版本更新必须同时完成桌面实机启动、SSH 验证和安全回归。依赖存在漏洞或破坏兼容性时，记录原因和临时固定版本，不以“最新”覆盖已验证的安全修复。
