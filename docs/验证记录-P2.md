## 安全边界与已知限制

- SQLite 只保存主机元数据和安全凭据引用字段，不包含密码、私钥或 Token；凭据管理属于 P3。
- Workspace 必须是绝对路径，拒绝 UNC、控制字符和 `..` 组件；不会自动创建或访问用户目录。
- `host_delete` 永远更新 `deleted_at`，不会删除审计历史；数据库物理备份和跨用户 ACL 验证属于 P5/P9。
- 当前数据库迁移基线为版本 1；改变已发布迁移 SQL 会触发 checksum mismatch，必须新增版本迁移。
